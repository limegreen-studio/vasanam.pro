# Contributing to VASANAM

Simple-a irukkum, promise.

## Setup

```bash
git clone https://github.com/bharathbr159-alt/VASANAM.git
cd VASANAM/web
npm install
npm run dev
```

## Konjam rules

1. Small, focused PRs pannunga — one feature/fix per PR nalladhu.
2. `npm run build` and `npm run lint` (inside `web/`) run pannunga commit pannurathukku munnadi, errors edhuvum varakoodadhu.
3. Puthu dialogue add pannanumna, `web/public/dialogues.json` la add pannunga — format:
   ```json
   { "dialogue": "your line here", "highlights": [{ "textToHighlight": "word", "image": "https://podu.pics/..." }] }
   ```
4. Real meme images add pannuradhu na welcome — placeholder links replace pannalam.
5. Commit messages clear-a eluthunga, enna maathiningo nu puriyanum.

## Bug report / feature request

GitHub Issues la open pannunga. Steps to reproduce, screenshots (irundha), expected vs actual — idhu podhum.

## Code of conduct

Chill-a irungo. Nalla vibe la contribute pannunga, adhu dhaan main rule.
